### 🚀 How to Import into n8n
1. Open your n8n workspace.
2. Click **Add workflow** or navigate to an existing workflow canvas.
3. Open the top-right menu (three dots `⋮`) and select **Import from File...** (or copy the raw JSON content and paste directly onto the canvas with `Ctrl + V`).
4. Click **Test workflow** to run it immediately!
